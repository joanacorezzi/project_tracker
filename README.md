# Simple Project Management CLI 
This is a small command-line project management tool written in Python.

- Python classes and objects (OOP)
- File I/O with JSON
- Command-Line Interface (CLI) with `argparse`
- Using an external package from PyPI (`tabulate`)
- Basic relationships:
  - One-to-many: User -> Projects
  - One-to-many: Project -> Tasks

## Setup

1. Python 3 installed (needed).

2. Install dependencies:

```bash
pip3 install -r requirements.txt
